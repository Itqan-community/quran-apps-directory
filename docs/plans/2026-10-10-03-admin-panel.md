## Global Constraints

- Versions (already pinned in repo): next `16.4.0`, react `19.3.0`, drizzle-orm `0.45.3`, zod `4.6.5`, tailwindcss `4`, `next-auth ^5.0.0-beta.32`. **Add:** `nodemailer ^7` + `@types/nodemailer`.
- No public REST; only internal handlers (`/health`, `/upload` new, `/sentry-tunnel`). Admin mutations are server actions only.
- Admin pages: dynamic, uncached (`cacheComponents` mode → wrap page content in `<Suspense>`); public reads stay behind `lib/cache/*` wrappers.
- Every mutation action ends with the matching `revalidateTag("apps"|"submissions"|"categories"|"metadata")` (R6); public pages consume only those tags via `lib/cache/*`.
- Admin is Arabic-only RTL, hardcoded Arabic strings (existing `/admin/login` pattern); `dir="rtl"` on admin layout.
- Status enums (pinned from old models): app `draft|published|archived`; submission `pending|under_review|info_requested|approved|rejected`; platform `android|ios|web|cross_platform`.
- Names must stay unique across apps (`findDuplicateAppName`, enforced at write time, not DB index).
- Slug: `slugify(nameEn)` + collision suffix `-1`, `-2`, … (old `apps/models.py` loop) — regenerate only on create or when `nameEn` changes.
- Vitest conventions: raw `postgres` fixtures in `beforeAll`, exact-count assertions, `afterAll` cleanup, sequential files (config already set). Test DB: `npm run db:push:test`.
- Commits: `<Area> - <what>` style (e.g. `Admin Shell - dashboard page with counts`), matching repo history.
- **Prereq:** the working tree has uncommitted public-site changes; commit or stash them before starting so tasks commit their own files only.

## Review Focus

- **Double-approve race / re-submit:** approving an already-approved submission must fail with an invalid-transition error and create no second App (submission has created_app guard; idempotency test owns it).
- **Approval with missing media:** submission without icon or without en/ar main image must be blocked with a clear Arabic storage error — never publish a broken listing (Django blocked approval too).
- **R2 not configured:** every image path (upload, approve transfer) must fail with a readable Arabic message / `503 storage_not_configured`, not a 500 stack (`r2Configured()` gate + tests).
- **Name/slug collisions:** duplicate app name rejected like the public form; two apps with same English name get distinct slugs (`-1` suffix) and unique DB slug never violated.
- **Anonymous access:** all admin pages redirect to login via proxy; `/upload` without session AND without `ADMIN_API_KEY` header returns 401 (test owns it, page assertions in e2e).
